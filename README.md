# 🏔️ TrailMate - 스마트 등산 트래킹 앱

**TrailMate**는 공공데이터 API를 활용한 지능형 등산 가이드 및 트래킹 애플리케이션입니다.

## ✨ 주요 기능

### 🎯 실시간 등산로 추천 시스템
- **공공데이터 기반**: 산림청 산정보 API 및 100대 명산 API 연동
- **지능형 추천 알고리즘**: 위치, 난이도, 날씨, 인기도 기반 개인화 추천
- **실시간 데이터**: 30분 캐싱으로 최신 정보 제공

### 📍 정밀 GPS 트래킹
- **실시간 위치 추적**: 5초 간격 GPS 업데이트 (5m 이동 시 감지)
- **정확한 거리 측정**: 이동 거리 실시간 계산
- **고도 추적**: 상승고도 및 현재 고도 모니터링
- **이중 제공자**: GPS + 네트워크 위치 제공자 동시 사용
- **권한 관리**: 세밀한 위치 권한 체크 및 요청
- **칼로리 계산**: 개인 신체 정보 기반 소모 칼로리 추정

### 📊 상세 기록 관리
- **월간 통계**: 등산 횟수, 총 거리, 상승고도 분석
- **등산 기록**: 날짜별 상세 기록 및 완주 여부
- **성과 달성**: 배지 시스템으로 동기 부여

### 🗺️ 카카오 지도 통합
- **실시간 지도 표시**: 카카오맵 API 2.12.8 기반 정확한 지도
- **GPS 위치 연동**: 실시간 GPS 위치 기반 지도 중심 이동
- **지도 컨트롤**: 줌인/아웃, 현재 위치로 이동, 새로고침
- **상태 표시**: GPS 연결 상태 실시간 표시 (연결 중/연결됨)
- **좌표 정보**: 현재 위치 좌표 및 고도 정보 표시
- **생명주기 관리**: 최적화된 메모리 사용 (pause/resume)

### 🌤️ 실시간 정보
- **날씨 정보**: 현재 위치 기반 날씨 상태
- **배터리 모니터링**: 실시간 배터리 잔량 표시
- **위치 정보**: GPS 정확도 및 속도 정보

### 🛡️ 견고한 오류 처리
- **API 접근 거부 대응**: SERVICE_ACCESS_DENIED 자동 감지
- **적응형 데이터 파싱**: XML/JSON 응답 자동 처리
- **지능형 Fallback**: 위치별 맞춤 대체 데이터 제공
- **사용자 친화적 메시지**: 기술적 오류를 이해하기 쉬운 문구로 변환

## 🛠️ 기술 스택

### Frontend
- **Jetpack Compose**: 모던 UI 프레임워크
- **Material Design 3**: 일관된 사용자 경험
- **Navigation Compose**: 화면 간 네비게이션

### Architecture
- **MVVM Pattern**: Model-View-ViewModel 아키텍처
- **StateFlow**: 반응형 데이터 스트림
- **Kotlin Coroutines**: 비동기 프로그래밍

### Data & API
- **공공데이터포털 API**: 산림청 산정보, 100대 명산
- **카카오맵 API**: 실시간 지도 표시 및 위치 서비스
- **LocationManager**: 안드로이드 네이티브 GPS
- **kotlinx.serialization**: JSON 데이터 파싱

### Performance
- **다층 캐싱**: 메모리 + 로컬 스토리지 + 데이터베이스 (30분 TTL)
- **스마트 에러 처리**: API 오류 시 즉시 Fallback 데이터 제공
- **배치 처리**: API 호출 최적화 및 재시도 로직
- **적응형 응답**: XML/JSON 자동 감지 및 파싱

## 🚀 핵심 기능 상세

```kotlin
추천 알고리즘 가중치:

### 2. 실시간 트래킹

트래킹 데이터:
├── 이동 거리: 실시간 GPS 기반 정확한 거리 측정
├── 경과 시간: 밀리초 단위 정밀 시간 측정
├── 평균 속도: 구간별 속도 계산

├── 현재 고도: 실시간 해발 고도
└── 칼로리: METs 기반 개인화 계산

├── 산림청 산정보 서비스
│   ├── 전국 산 정보 조회
│   ├── 지역별 필터링
│   ├── SERVICE_ACCESS_DENIED 자동 감지
│   └── 100대 명산 여부 확인
├── 100대 명산 목록 서비스
│   ├── 상세 산 정보
│   ├── GPS 좌표
│   ├── XML/JSON 적응형 파싱
│   └── 개요 및 특징
└── 다단계 오류 처리 시스템
    ├── API 오류 감지 및 로깅
    ├── 사용자 친화적 메시지 변환
    ├── 지역별 Fallback 데이터 제공
    └── 실시간 추천 등산로 생성
```

## 🔧 설치 및 실행

### 요구사항
- Android 8.0 (API 레벨 26) 이상
- GPS 기능 지원 디바이스
- 인터넷 연결 (API 통신용)

### 권한
```xml
<uses-permission android:name="android.permission.ACCESS_FINE_LOCATION" />
<uses-permission android:name="android.permission.ACCESS_COARSE_LOCATION" />
<uses-permission android:name="android.permission.INTERNET" />
<uses-permission android:name="android.permission.ACCESS_NETWORK_STATE" />
```

### 빌드 방법
```bash
git clone https://github.com/your-repo/TrailMate.git
cd TrailMate
./gradlew assembleDebug
```

### ⚠️ API 접근 제한 대응
현재 산림청 및 100대 명산 API에서 서비스 접근 거부(`SERVICE_ACCESS_DENIED_ERROR`)가 발생하고 있습니다. 
이는 API 서비스 키 권한 또는 서비스 상태와 관련된 문제로, 앱에서는 다음과 같이 대응합니다:

#### 🔧 자동 대응 시스템
1. **오류 감지**: API 응답에서 `returnReasonCode=20` 자동 감지
2. **Fallback 데이터**: 지역별 맞춤 등산로 추천 즉시 제공
3. **사용자 알림**: "서버 점검 중입니다. 기본 추천 등산로를 표시합니다."
4. **재시도 버튼**: 사용자가 수동으로 API 재시도 가능

#### 📍 Fallback 데이터 제공 지역
- **서울**: 북한산, 관악산, 남산, 인왕산, 안산 (5개)
- **경기**: 광교산, 청계산, 수리산, 용문산, 명지산 (5개)  
- **전국**: 지리산, 설악산, 한라산, 계룡산 등 (명산 위주)

#### 🛠️ API 문제 해결 방법
```bash
# API 로그 확인
adb logcat | grep "ForestService\|MountainRepository"

# 주요 에러 코드:
# - returnReasonCode=20: SERVICE_ACCESS_DENIED_ERROR
# - 해결: 공공데이터포털에서 서비스 키 권한 재신청 필요
```
