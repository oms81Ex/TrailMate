# PeakPal UI 와이어프레임 설계서

## 1. 전체 네비게이션 구조

```
┌─────────────────────────────────────────┐
│                 상단바                   │
│  📍 위치 | 🌤 날씨 | 🔋 배터리 | ⚙️ 설정  │
├─────────────────────────────────────────┤
│                                         │
│                                         │
│              메인 컨텐츠 영역               │
│                                         │
│                                         │
├─────────────────────────────────────────┤
│              하단 네비게이션               │
│  🏠    🚀    📊    👥    ⚙️           │
│ 홈   트래킹  기록  커뮤니티 설정          │
└─────────────────────────────────────────┘
```

### 1.1 정보 계층 구조
```
App Root
├── Auth Stack (로그인/회원가입)
├── Main Tab Navigator
│   ├── Home Stack (홈/지도)
│   ├── Tracking Stack (트래킹)
│   ├── Records Stack (기록)
│   ├── Community Stack (커뮤니티)
│   └── Settings Stack (설정)
├── Modal Stack (팝업, 오버레이)
└── Emergency Stack (SOS 모드)
```

- **지도 제스처**: 팬, 줌, 회전 지원

- **등산로 탭**: 등산로 상세 정보 모달

#### 2.5.1 SOS 단계별 프로세스
```
1. SOS 버튼 3초 이상 길게 누름
   ↓
2. 3초 카운트다운 시작 (취소 가능)
   ↓
3. 현재 위치 GPS 고정
   ↓
4. 응급상황 모드 활성화
   ↓
5. 자동 알림 전송
   - 119 (선택 시)
   - 등록된 비상연락처
   - 주변 앱 사용자
   ↓
6. 실시간 위치 추적 시작
   ↓
7. 배터리 절약 모드 자동 활성화
```

## 9. 성능 최적화

### 9.1 이미지 최적화
```
이미지 포맷:
├── 아이콘: SVG (벡터)
├── 사진: WebP → JPEG fallback
├── 썸네일: 저화질 JPEG (50KB 이하)
└── 고해상도: Progressive JPEG

로딩 전략:
├── Lazy Loading: 스크롤 시 로드
├── Placeholder: 저화질 이미지 먼저 표시
├── Caching: 로컬 스토리지 활용
└── CDN: 지역별 최적화된 서버
```

### 9.2 데이터 최적화
```
GPS 데이터:
├── 압축: gzip 압축 전송
├── 배치: 10초마다 일괄 전송
├── 필터링: 정확도 낮은 데이터 제외
