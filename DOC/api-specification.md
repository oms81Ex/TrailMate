# PeakPal 등산 트레킹 앱 프로젝트

## 프로젝트 개요
- 앱명: PeakPal (피크팰)
- 목적: 안전하고 즐거운 등산을 위한 종합 트레킹 앱
- 주요 기능: GPS 트래킹, 안전 관리, 커뮤니티, 등산 기록

## 핵심 기능
1. 실시간 GPS 트래킹 및 내비게이션
2. SOS 긴급상황 대응 시스템  
3. 등산 기록 및 통계 관리
4. 커뮤니티 기반 정보 공유
5. 오프라인 지도 및 안전 기능

## 기술 스택 (예정)
- Frontend: React Native
- Backend: Node.js + Express
- Database: PostgreSQL + MongoDB
- Map: Google Maps API
- Cloud: AWS

## 개발 원칙
- 사용자 안전 최우선
- 직관적인 UI/UX
- 오프라인 기능 지원
- 한국 등산로 특화

1. API 개요
1.1 기본 정보
Base URL: https://api.peakpal.com/v1
Protocol: HTTPS only
Authentication: JWT Bearer Token
Content-Type: application/json
Rate Limiting: 1000 requests/hour per user

Content-Type: application/json
