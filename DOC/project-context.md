# PeakPal 프로젝트 컨텍스트

## 1. 프로젝트 개요

### 1.1 프로젝트 정보
```yaml
프로젝트명: PeakPal (피크팰)
버전: 1.0.0
개발 기간: 2025년 5월 ~ 2025년 9월 (4개월)
팀 구성: 4명 (PM 1, 개발자 2, 디자이너 1)
예산: $50,000
목표 플랫폼: iOS, Android
```

### 1.2 비즈니스 목표
- **안전한 등산 환경 조성**: GPS 트래킹과 SOS 기능으로 등산객 안전 보장
- **커뮤니티 활성화**: 등산 정보 공유 및 동행 매칭을 통한 등산 문화 확산  
- **개인화된 등산 경험**: AI 기반 맞춤형 등산로 추천 및 개인 기록 관리
- **수익 창출**: 프리미엄 구독, 장비 판매 제휴, 광고를 통한 지속 가능한 비즈니스 모델

### 1.3 핵심 가치 제안
- 🛡️ **안전 우선**: 실시간 위치 추적과 응급상황 대응
- 🎯 **한국 특화**: 국내 등산로 전문 정보와 문화 반영
- 👥 **커뮤니티**: 등산객들 간의 정보 공유와 소통
- 📱 **오프라인 지원**: 산속에서도 사용 가능한 핵심 기능

## 2. 시장 분석

### 2.1 타겟 시장
```yaml
Primary Market:
  - 규모: 국내 등산 인구 1,800만명 (전체 인구의 35%)
  - 특성: 20-50대, 중산층, 건강 관심층
  - 성장률: 연간 5-7% 증가 (팬데믹 이후 아웃도어 활동 급증)

Secondary Market:
  - 해외 등산객 (한국 여행)
  - 트레킹/하이킹 입문자
  - 자연 관광객
```

### 2.2 경쟁사 분석
```yaml
직접 경쟁사:
  - 산정상(Mountain Top): 국내 1위, 등산로 정보 중심
  - 트레킹맵: GPS 트래킹 특화, 오프라인 지도 강점
  - 등산스쿨: 커뮤니티 중심, 등산 교육 콘텐츠

간접 경쟁사:
  - Strava: 스포츠 트래킹 앱
  - AllTrails: 글로벌 등산로 플랫폼
  - Gaia GPS: 아웃도어 내비게이션

차별화 포인트:
  - 통합적 안전 관리 시스템
  - 한국 등산 문화 특화 기능
  - 실시간 그룹 트래킹
  - AI 기반 개인 맞춤 추천
```

### 2.3 시장 기회
- **코로나19 이후 아웃도어 활동 급증**: 실내 활동 제한으로 등산 인구 30% 증가
- **디지털 네이티브 등산객 증가**: MZ세대의 등산 참여율 급상승
- **안전 의식 강화**: 등산 사고 증가로 안전 기능에 대한 니즈 확대
- **스마트폰 보급률**: 99% 보급률로 모바일 앱 접근성 최적

## 6. 기술 결정 사항

### 6.1 아키텍처 선택 이유
```yaml
React Native 선택 이유:
  - 크로스 플랫폼 개발로 개발 기간 단축
  - 네이티브 성능과 유사한 GPS 기능 지원
  - 풍부한 지도 관련 라이브러리 생태계
  - 팀의 JavaScript/TypeScript 경험 활용

Node.js + Express 선택 이유:
  - 실시간 통신 (WebSocket) 지원 우수
  - JSON 기반 API 개발에 최적화
  - 마이크로서비스 아키텍처 구현 용이
  - 빠른 프로토타이핑 및 개발 속도

AWS 클라우드 선택 이유:
  - 글로벌 인프라와 높은 안정성
  - 다양한 관리형 서비스 (RDS, S3, Lambda)
  - 오토스케일링으로 트래픽 증가 대응
  - 한국 리전 존재로 낮은 지연시간
```

### 6.2 써드파티 서비스 선택
```yaml
Google Maps API:
  - 높은 정확도와 실시간 업데이트
  - 풍부한 POI 데이터
  - 오프라인 지도 지원
  - 한국 지역 최적화

기상청 API:
  - 정확한 한국 날씨 데이터
  - 무료 사용 가능
  - 실시간 기상특보 제공

Firebase:
  - 푸시 알림 서비스
  - 실시간 데이터베이스
  - 사용자 분석
  - 간편한 설정 및 관리
```
